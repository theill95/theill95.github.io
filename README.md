# Jonas Theill Bøjstrup — personal website

Eight static pages in English and Danish, three downloadable papers, and a two-page English CV. No build or account is required to run the website.

## Publish on GitHub Pages

1. Create a public repository named `theill95.github.io` under the `theill95` account.
2. Upload the contents of this folder into the repository root, including `assets`, `papers`, and `da`. Do not put them inside another folder.
3. In Settings → Pages, select **Deploy from a branch**, then **main**, **/ (root)**, and Save.
4. The resulting address will be `https://theill95.github.io/`.

The existing `mlfin-2026` repository and course site are independent. This website links to that course without changing it.

## Editing

- English pages are in the root; corresponding Danish pages are in `da/`.
- Layout and colours: `assets/style.css`.
- Citation-copy and print buttons: `assets/site.js`.
- Portrait: `assets/portrait.webp`.
- CV: `assets/jonas-theill-bojstrup-cv.pdf`.
- Manuscripts: `papers/`.
- Update both languages when changing content. Paper summaries occur on the homepage and research page; paper titles also appear in the CV.
- The current PDF is in English; both language versions link to it.
- Dates and information reflect the material supplied in October 2026. Update the expected PhD completion and research visit as needed.
